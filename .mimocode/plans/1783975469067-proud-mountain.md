# Plano: Reorganizar Area Administrativa - 100% Responsiva e Funcional

## Contexto

A area administrativa (`/admin`) do ImobWeb esta quase vazia:
- Apenas 2 paginas existem: redirect e um dashboard com KPIs placeholder ("--")
- O `AdminSidebar` ja esta construido mas NAO esta integrado em nenhum layout
- NAO existe `app/admin/layout.tsx`
- Das ~30 sub-rotas definidas em `menu-config.ts`, nenhuma existe como pagina
- NAO existem API routes sob `/api/admin/`
- Os dados do dashboard sao hardcoded/mockados

## Objektivo

Criar uma area administrativa completa, responsiva, com dados reais e funcoes funcionais.

---

## Arquivos a Criar/Modificar

### 1. Layout Admin (NOVO)

**`app/admin/layout.tsx`** - Layout com sidebar responsiva
- Integrar `AdminSidebar` existente
- Mobile: sidebar vira drawer (hamburger menu) usando padrao do `ResponsiveSidebar`
- Tablet: sidebar colapsada (icones apenas)
- Desktop: sidebar expandida
- Header com titulo da pagina, busca global, notificacoes e menu do usuario

### 2. Dashboard Administrativo (REESCRVER)

**`app/admin/dashboard/page.tsx`** - Dashboard com dados REAIS

- Atividade recente

### 3. Paginas Administrativas (NOVAS)

### 4. API Routes Administrativas (NOVAS)

**`app/api/admin/stats/route.ts`** - Stats consolidados do admin
- Agrega dados de `/api/tenant`, `/api/analytics/kpis`, subscriptions
- Retorna: totalOrgs, activeOrgs, totalMRR, newMRR, churnRate, totalUsers

**`app/api/admin/organizations/route.ts`** - Listagem admin de organizacoes
- Busca todas as organizacoes via Prisma com stats
- Suporta busca, filtro por status, paginacao

**`app/api/admin/organizations/[id]/route.ts`** - Detalhe/atualizacao
- GET: detalhes da organizacao
- PATCH: atualizar status (ativar/suspender/bloquear)
- DELETE: remover organizacao

**`app/api/admin/users/route.ts`** - Listagem admin de usuarios
- Busca todos os usuarios via Prisma com organizacao
- Suporta busca, filtro por role, paginacao

**`app/api/admin/users/[id]/role/route.ts`** - Alteracao de role
- PATCH: alterar role do usuario

## Responsividade - Padrão a Seguir

Todas as paginas devem seguir o padrao responsivo existente:

1. **Mobile (< 768px)**:
   - Sidebar vira drawer com hamburger
   - Grids em 1 coluna
   - Tabelas viram cards verticais (usar `ResponsiveTable`)
   - Modais viram bottom sheets (usar `AdaptiveModal`)
   - Icones com overflow:hidden em containers com tamanho fixo
   - Padding responsivo: `px-4 sm:px-6 lg:px-8`

2. **Tablet (768-1023px)**:
   - Sidebar colapsada (icones apenas)
   - Grids em 2 colunas
   - Tabelas funcionam normalmente

3. **Desktop (>= 1024px)**:
   - Sidebar expandida
   - Grids em 3-4 colunas
   - Tabelas com todas as colunas

4. **Fix de icones saindo da tela**:
   - Todos os icones devem estar em containers com `overflow-hidden` e tamanho fixo
   - Usar `w-10 h-10` ou `w-12 h-12` com `rounded-xl` para icones
   - Nunca usar icones soltos sem container
