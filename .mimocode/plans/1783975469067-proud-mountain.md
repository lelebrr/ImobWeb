# Plano: Dropdowns Criáveis no Wizard de Vistoria

## Contexto

O wizard de vistoria (`app/admin/vistoria/page.tsx`) tem campos select com opções fixas. O usuário quer que:
1. A primeira opção de cada dropdown seja **"+ Criar"**
2. Ao selecionar "+ Criar", aparece um input para digitar um valor novo
3. O valor criado é salvo (localStorage) e aparece como opção nas próximas vezes
4. Valores já criados ficam disponíveis para selecionar novamente

## Campos Afetados

| Campo | Opções Atuais | storageKey |
|-------|---------------|------------|
| Tipo do Imóvel | APARTAMENTO, SALA, CASA, COMERCIAL, COBERTURA | `vistoria_tipo_imovel` |
| Finalidade | RESIDENCIAL, COMERCIAL | `vistoria_finalidade` |
| Mobiliado | NÃO, SIM, PARCIALMENTE | `vistoria_mobiliado` |

## Abordagem

### 1. Criar componente `CreatableSelect`

**`components/ui/creatable-select.tsx`** — Componente reutilizável:
- Props: `options` (fixas), `value`, `onChange`, `placeholder`, `storageKey`
- Renderiza `<select>` com opções fixas + "+ Criar" como **primeira opção**
- Quando "+ Criar" é selecionado → troca por `<Input>` + botão salvar
- Salva valores customizados no `localStorage` com a key `storageKey`
- Ao montar, carrega valores salvos e mergeia com opções fixas
- Design dark: `bg-white/5 border-white/5 text-white`, opções com `bg-[#12121a]`
- Ícone `Plus` ao lado de "+ Criar"

### 2. Atualizar `app/admin/vistoria/page.tsx`

- Substituir os 3 `<select>` do Step 0 por `<CreatableSelect>`
- Definir opções padrão como constantes:
```ts
const TIPO_IMOVEL_OPTIONS = ['APARTAMENTO', 'SALA', 'CASA', 'COMERCIAL', 'COBERTURA'];
const FINALIDADE_OPTIONS = ['RESIDENCIAL', 'COMERCIAL'];
const MOBILIADO_OPTIONS = ['NÃO', 'SIM', 'PARCIALMENTE'];
```

### 3. Persistência no localStorage

Schema:
```json
{
  "vistoria_tipo_imovel": ["APARTAMENTO", "SALA", "CASA", "COMERCIAL", "COBERTURA", "LOFT"],
  "vistoria_finalidade": ["RESIDENCIAL", "COMERCIAL", "MISTO"],
  "vistoria_mobiliado": ["NÃO", "SIM", "PARCIALMENTE", "MOBILIADO COM ELETRO"]
}
```

## Arquivos a Modificar

1. **`components/ui/creatable-select.tsx`** — NOVO componente
2. **`app/admin/vistoria/page.tsx`** — Trocar selects por CreatableSelect

## Verificação

1. Abrir wizard → Step 0
2. Select "Tipo do Imóvel" → "+ Criar" é a primeira opção
3. Selecionar "+ Criar" → input aparece → digitar "LOFT" → Enter/salvar
4. Select agora mostra "LOFT" como selecionado
5. Fechar e reabrir wizard → "LOFT" ainda está nas opções
6. Testar em Finalidade e Mobiliado
7. Opções fixas continuam aparecendo junto com as criadas
